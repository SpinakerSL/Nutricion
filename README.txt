MI NUTRICION v1.4
Búsqueda unificada: Local -> USDA FoodData Central -> Open Food Facts.
USDA exige una clave personal. Pégala dentro de Perfil y configuración; se guarda solo en el almacenamiento local del dispositivo y nunca debe subirse escrita en el código de GitHub.
La traducción español/inglés usa un diccionario local de términos alimentarios comunes. Los nombres USDA se muestran mediante traducción aproximada; revisa el alimento antes de agregarlo.
Para actualizar: reemplaza todos los archivos del repositorio, confirma el commit, espera GitHub Pages y abre primero la URL en Safari.
